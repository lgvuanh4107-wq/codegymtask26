Bài tập Nhúng CSS vào trang HTML

Phần 1: Inline Style

Đoạn văn này được thay đổi màu sắc bằng Inline Style (Màu đỏ).

Phần 2: Internal Style

Đoạn văn này được thay đổi màu sắc bằng Internal Style (Màu xanh lá).

Phần 3: External Style

Đoạn văn này được thay đổi màu sắc bằng External Style từ file style.css (Màu xanh dương).
